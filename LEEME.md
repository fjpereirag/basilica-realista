# Bienaventurados · web de la basílica

- `index.html`: la web nueva. Recorrido continuo controlado por el scroll, con las 15 paradas y las ocho Bienaventuranzas.
- `basilica-bienaventuranzas.html`: tu maqueta 3D original. La web nueva la enlaza al final.
- `frames/`: los fotogramas del recorrido. Ahora son **provisionales**, sacados de la maqueta.
- `keys/`: los 15 fotogramas clave en alta resolución, que son la guía de composición para la IA.
- `herramientas/GUIA-SEEDANCE.md`: paso a paso y prompts para generar la versión realista.
- `herramientas/guias/`: 14 vídeos con el movimiento de cámara de cada tramo, para usarlos como referencia en Seedance.
- `herramientas/convertir-video.bat`: convierte los 14 clips de Seedance en fotogramas para la web.

Para verla en local, abre `index.html` con doble clic. Para publicarla, sube la carpeta entera a un repositorio de GitHub Pages, como tus otras webs.
